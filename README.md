## Pasaporte de idiomas

App web sin dependencias (HTML, CSS y JavaScript) para aprender alemán, inglés, italiano, chino y francés.

- **Rutina diaria** por día de la semana, con racha de días seguidos.
- **Tarjetas** con repaso espaciado: 6 cajas con intervalos de 0, 1, 3, 7, 14 y 30 días, y un límite de palabras nuevas al día.
- **Pronunciación** con la Web Speech API del navegador.
- **Plan por fases** con niveles del Marco Común Europeo (A1–C2) y exámenes oficiales.
- **Progreso** semanal por idioma.
- Dentro de Claude, la app guarda el progreso en la nube y permite conversar con Claude como tutor que corrige los errores.
