Proyecto propio · Machine learning

dataGol: quién ganará el Mundial 2026

Aplicación pública en Streamlit · Python

Reto

Estimar qué selección ganará el Mundial a partir de datos históricos.

Solución

Modelo combinado de Regresión Logística, Random Forest y XGBoost con datos de ocho fuentes, y simulación Monte Carlo de todo el cuadro del torneo.

Resultado

Probado con los Mundiales de 2018 y 2022: el campeón real estuvo siempre entre los 5 favoritos del modelo.

  • scikit-learn
  • XGBoost
  • Monte Carlo
